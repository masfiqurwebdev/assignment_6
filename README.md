# DigiTools

DigiTools is a modern and responsive digital products marketplace built with React and Tailwind CSS. Users can browse premium digital tools, add products to a shopping cart, view the total price, and complete a simple checkout process with a clean and intuitive user interface.

---

## Live Demo

> https://your-live-demo-link.com

---

## Features

- Browse premium digital products with a responsive card layout.
- Add products to the cart with dynamic **"Added to Cart"** button state.
- View cart, remove items, calculate total price, and complete checkout with toast notifications.

---

## Technologies Used

- React.js
- Tailwind CSS
- JavaScript (ES6)
- Lucide React Icons
- React Hot Toast

---

## Core Functionalities

- Responsive UI for desktop, tablet, and mobile.
- Product & Cart toggle functionality.
- Dynamic cart count.
- Add/Remove products.
- Automatic total price calculation.
- Checkout success notification.
- Cart resets after successful checkout.
